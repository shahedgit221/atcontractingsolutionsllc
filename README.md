ANIMATION & MOTION DESIGN

This is extremely important.

Use the reference website's LEVEL OF ANIMATION QUALITY as inspiration.

Create a consistent premium motion system throughout the website.

Use:

* cinematic hero entrance
* smooth scroll reveals
* staggered element animations
* image reveal animations
* subtle parallax
* premium card hover effects
* image zoom
* button micro-interactions
* smooth navbar transition on scroll
* elegant section transitions

Use smooth easing similar to:

cubic-bezier(0.22, 1, 0.36, 1)

Most animations should be approximately 400–900ms.

Animations should feel expensive and intentional.

Avoid:

* excessive bouncing
* spinning
* flashy effects
* random movement
* over-animation

The website should feel smooth while scrolling from beginning to end.
